# mieru

mieru (見える, "visible") is a web service for model repositories: upload a neural-network model (ONNX or safetensors) with a README, explore it as an interactive computation graph or module tree with parameter statistics, discuss it in issues, star it, and share it with fine-grained access control (private, specific people, expiring links, or public; viewer and editor roles). It is a React + Vite SPA backed by a Fastify (Node.js, TypeScript) API, MySQL accessed through raw SQL, and local-disk storage, deployed with Dokploy. See [`docs/plans/mieru.md`](docs/plans/mieru.md) for the implementation plan.
